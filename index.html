ANAV - IROC-U 2025 Abstract

This project presents the software and algorithm architecture for an Autonomous Navigation Aerial Vehicle (ANAV) developed for IROC-U 2025, engineered specifically for GPS-denied navigation and exploration. The system integrates multi-sensor inputs—including IMU, LiDAR, and cameras—through comprehensive sensor fusion, Extended Kalman Filtering (EKF), visual odometry, and SLAM to enable autonomous localization and path planning. Key architectural contributions include a proposed embedded AI framework for real-time decision-making, obstacle avoidance, and autonomous landing, supported by PID-based flight control loops. Additionally, the system features robust software-level failsafe mechanisms, including emergency landing, Return-to-Home (RTH), and fail-safes for power and communication disruptions.
